# シェルメニュー画像・システム画像仕様（menu/foreground.png, ssp-pictures）

## 概要

`ghost/<ghost>/shell/<shell>/menu/foreground.png`（および `background.png` 等）や、SSP 本体の `data/ssp-pictures/` に格納される画像群の規格上の位置づけと仕様です。

---

## 1. シェルメニュー画像 (`menu/foreground.png`)

### 規格上の根拠（ukadoc / オーナードローメニュー仕様）

- **元規格**: [manual/owner-draw-menu.md](https://github.com/ukatech/ukadoc-spec/blob/main/manual/owner-draw-menu.md)
- **関連設定**: シェルの `descript.txt` 内の定義
  - `menu.background.bitmap.filename,background.png`（メニュー全体の背景画像）
  - `menu.foreground.bitmap.filename,foreground.png`（カーソル選択行・ハイライト部分の前景画像）
  - `menu.sidebar.bitmap.filename,sidebar.png`（サイドバー画像）
- **役割**:
  - シェルごとの右クリックメニュー（オーナードローメニュー）をスキン化するための画像群です。
  - `menu/foreground.png` は、項目にホバー・選択フォーカスが当たった際に背景画像の上に重ねて描画されるハイライト／前景スキン画像として使用されます。
- **配置パス例**:
  - `ghost/emily4/shell/master/menu/foreground.png`
  - `ghost/emily4/shell/master/menu/background.png`
  - `ghost/emily4/shell/master/menu/sidebar.png`
- **フォールバック**:
  - 定義および画像が存在しない場合、ベースウェア標準のメニューデザイン・色設定が適用されます。

## 2. SSP / MATERIA 風 起動時・処理中ステータスバナー（「処理中」ウィンドウ）

### 画面レイアウト・表示仕様

伺か／MATERIA・SSPにおいて、起動時やSHIORIロード中・重いイベント処理中に表示されるステータス表示ウィンドウ（処理中バナー）の構成仕様です：

```text
+-------------------------------------------------------------+
|  [ゴーストバージョン等]                  【 処 理 中 】     |  <- 上部 (約 3:2 の 3 相当)
|                                                             |
+-------------------------------------------------------------+
|  ゴースト名 (例: 「エミリ」)                                |  <- 下部 (約 3:2 の 2 相当)
+-------------------------------------------------------------+
```

- **上下 3:2 分割の構造**:
  - **上段（約 3）**:
    - **左上（小フォント）**: ゴーストのバージョン番号や著作情報・システム情報。
    - **右上（太字・大フォント）**: 「**処理中**」（あるいは動作状態ステータス）。
  - **下段（約 2）**:
    - **下部（中フォント）**: 対象ゴースト名（`descript.txt` の `name`）。
- **背景・装飾**:
  - ベースウェア共通の標準システムスタイル（濃紺／ダークグレー基調、または半透明ウィンドウによる矩形バナー）。独自スキンの合成は行わない。
- **表示位置（ウィンドウ配置座標）**:
  - 対象モニター画面において、**メニュー表示位置の左右反対側の下側**に配置する。
  - 例: メニューがタスクトレイ近傍の画面右下基準（`pos.x + width - 260`, `pos.y + height - 560`）の場合、バナーは**画面左下基準**（`pos.x + 20`, `pos.y + height - 140` など）に配置し、操作メニュー・通知領域との重複を回避する。
- **目的と消去タイミング**:
  - プロセス起動から SHIORI の初期化（`load` 完了）、`OnBoot` 応答の受け取り、初期サーフィスの描画準備が整うまで最前面に表示。
  - サーフィス表示完了と同時にフェードアウト／即時非表示。

## 3. SSP システム画像群 (`ssp/data/ssp-pictures/`)

### 規格・SSP 内部仕様上の位置づけ

- **役割**:
  - SSP 本体（ベースウェア）がシステム状態やダイアログ、処理中インジケータ等を表示するために同梱している共通リソース領域です。
- **代表的な格納画像と使途**:
  - `shiori.png` / `load.png` 等: SHIORI やゴーストの読み込み中・処理中を表すインジケータ／ダイアログ画像。
  - `network.png` / `update.png`: ネットワーク更新処理中・通信中の表示用。
  - `caution.png` / `error.png`: 警告・エラーポップアップ用。
- **ベースウェアにおける挙動**:
  - ゴーストの起動時、SHIORI DLL のロード中、時間のかかるイベント処理中などに、ユーザーへ「処理中」であることを明示するスプラッシュやダイアログのビジュアルとして使用されます。

---

## 3. 本アプリケーション（nanai-android-mascot）における活用方針

### (1) オーナードローメニューのスキン適用

- `ui/menu-iframe.html` において、現在選択中のシェルの `descript.txt`（`menu.*.bitmap.filename`）または `shell/<shell>/menu/` 配下の画像（`foreground.png`, `background.png`, `sidebar.png`）を読み込み、メニューコンテナやホバー時の背景スタイル（CSS）に動的に反映します。

### (2) 起動時／処理中ウィンドウへの適用

- ゴースト起動中（SHIORI ロード中、アセット準備中）のローディング表示において：
  - **ゴースト固有**: シェルのサムネイル（`thumbnail.png`）やシェルのメニュー画像（`menu/background.png` 等）を背景／ビジュアルとして活用。
  - **システム共通**: `data/ssp-pictures/` 相当のローディング・処理中インジケータ（スピナーやシステムアイコン）をオーバーレイ表示し、処理中であることを明示。
