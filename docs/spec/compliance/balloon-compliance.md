# バルーン規格対応仕様 (Balloon Compliance)

- **元ドキュメント・権利者**: [ukatech/ukadoc-spec: surfaces.txt / balloon](https://ukatech.shillest.net/ukadoc-spec/) - © MATERIA開発チーム / SSP開発チーム / ukadoc プロジェクト (ukadoc 仕様 / パブリックリファレンス)
Nanai Android Mascot における「バルーン（吹き出し）スキン規格（`balloon/descript.txt`）」および表示制御への個別対応仕様です。

## 1. 概要と対応度

- **規格**: 伺か/SSP バルーン仕様、Modern Web CSS/Theme
- **対応度**: **75%**
- **主要実装ファイル**:
  - `src/css/mascot.css`: バルーン配置、吹き出し装飾、タイポグラフィ
  - `src/js/sakura-script.js`: `\0` / `\1` スコープ別バルーンへの送出制御
  - `src/js/modal-manager.js`: バルーン着せ替えテーマ管理

---

## 2. 仕様対応詳細

| 項目 / 規格 | 対象仕様 | 対応状況 | 動作仕様・実装詳細 |
| :--- | :--- | :---: | :--- |
| **独立バルーン表示** | `\0` (メイン) / `\1` (サブ) | ✅ 対応済 | 各キャラの頭上・横位置へ独立した吹き出しコンテナを動的配置 |
| **バルーンテーマ着せ替え** | プリセットテーマ切替 | ✅ 対応済 | モダン（デフォルト）、アイボリー、コミック、ダークの動的切り替え |
| **バルーン倍率変更** | 80% / 100% / 120% / 150% | ✅ 対応済 | メニューから文字・吹き出しサイズのリアルタイム拡縮 |
| **文字送り・自動スクロール** | テキストキューイング | ✅ 対応済 | 指定ウェイトに応じた文字送り、あふれ時のスムーズなスクロール |
| **選択肢レンダリング** | `\q` ボタン生成 | ✅ 対応済 | タッチ・クリック操作しやすいボタン形式でのインライン描画 |
| **`descript.txt` 座標解釈** | `origin.x`, `validrect` 等 | 🚧 開発中 | 既存レガシーバルーンスキンの画像スライス・9スライス解釈 |
| **オンライン着せ替え** | 追加バルーン導入 | 🚧 開発中 | `assets/balloon/` 配下への独自スキン導入と自動探索 |

---

## 3. モバイル向け適応

- **画面端・はみ出し自動補正**: 画面端にキャラクターが移動した際、バルーンが画面外へ見切れないよう自動で左右反転・位置補正。
- **タップによるスキップ**: バルーン領域タップで表示中テキストを一括全文表示。
