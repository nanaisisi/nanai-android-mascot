# システムトレイメニューの起点位置と SSP / 伺かとの挙動比較

本ドキュメントは、Tauriアプリケーションにおけるシステムトレイアイコンクリック時のメニューポップアップ位置（起点座標）に関する設計思想および、本家SSP（伺か）との挙動の比較に関する知見を記録するものです。

---

## 1. 座標計算の仕組み (`rect` の活用)

- `TrayIconEvent::Click` が提供する `rect`（トレイアイコンの画面上の絶対矩形）を利用し、アイコンの左下（`x = rect.position.x`, `y = rect.position.y + rect.size.height`）を基本起点としてメニューを展開する実装を採用しています。

## 2. 本家 SSP との挙動の比較

- 本家 SSP（伺か）においても、システムトレイアイコンのクリック位置が常に完全に厳密な左下を起点にしているわけではありません。
- 実際の Windows ネイティブの挙動と同様に、ややカーソルの先端より上（またはタスクバーのトレイアイコンのバウンディングボックス周辺）にわずかなオフセットを持ってポップアップする挙動が見られます。
- 当アプリケーションでもこのネイティブ仕様を踏襲しつつ、アイコンの矩形情報を基準とした直感的なポップアップ位置となるよう調整を行っています。
