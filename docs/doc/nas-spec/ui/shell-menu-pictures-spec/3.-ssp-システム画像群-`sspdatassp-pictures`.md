## 3. SSP システム画像群 (`ssp/data/ssp-pictures/`)

### 規格・SSP 内部仕様上の位置づけ

- **役割**:
  - SSP 本体（ベースウェア）がシステム状態やダイアログ、処理中インジケータ等を表示するために同梱している共通リソース領域です。
- **代表的な格納画像と使途**:
  - `shiori.png` / `load.png` 等: SHIORI やゴーストの読み込み中・処理中を表すインジケータ／ダイアログ画像。
  - `network.png` / `update.png`: ネットワーク更新処理中・通信中の表示用。
  - `caution.png` / `error.png`: 警告・エラーポップアップ用。
- **ベースウェアにおける挙動**:
  - ゴーストの起動時、SHIORI DLL のロード中、時間のかかるイベント処理中などに、ユーザーへ「処理中」であることを明示するスプラッシュやダイアログのビジュアルとして使用されます。
