# 右クリックメニュー・サブメニュー仕様書 (Context Menu Specification)

## 1. 概要

伺か（SSP）互換の右クリック操作により展開される、ポップアップメニューの表示制御およびサブメニューの展開仕様を定めます。
本機能は、マスコットウィンドウ枠外へのはみ出し表示を可能とする独立Tauriウィンドウ、およびブラウザ/Android環境向けのインラインiframeフォールバックの双方で共通のデザイン・挙動を提供します。

## 2. メニュー本体の画面内収束 (SSP準拠)

1. **基本表示基点**:
   - マスコットのクリック座標または右クリック位置を基点として表示。
2. **画面端（モニター境界）での自動収束**:
   - プライマリモニターの作業領域（幅・高さ）を取得し、メニューウィンドウ全体のサイズ（横展開サブメニュー領域を含む幅500px、高さ520px）が画面右端・下端を超えないよう自動でクランプ補正（左上方向へオフセット）します。
   - ウィンドウが画面外に押し出されたり、切り取られることを防止します。
3. **メインメニュー内のスクロール**:
   - 項目数が多い場合でも、`.menu-container` に `max-height: calc(100vh - 1rem)` および `overflow-y: auto` を適用し、薄型スクロールバーにてメニュー内完結でスクロール可能です。

## 3. サブメニューのフライアウト展開仕様

SSP標準のUI体験に基づき、確定的かつ自然な横展開を提供します。

1. **インジケータ表示**:
   - サブメニューを持つ親項目には右向き矢印（`▶`）を表示。
2. **展開方向**:
   - **基本（デフォルト）**: 親項目の**右側**（`left: calc(100% + 2px)`）に整然とフライアウト展開。
   - **画面端判定（反転）**: 親メニューの右側にサブメニューを展開する十分なスペース（約240px以上）が存在しない場合、自動的に `flip-left` クラスを適用し、親項目の**左側**（`right: calc(100% + 2px)`）へ綺麗に反転展開。
3. **独立スクロール**:
   - サブメニュー（ゴースト一覧やシェル一覧など項目数が増加するリスト）も `max-height: calc(100vh - 2rem)` および `overflow-y: auto` により、個別に縦スクロールが可能です。
