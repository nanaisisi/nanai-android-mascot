# 各論3：改変性・拡張性 (Modifiability & Extensibility)

## 1. 保守性と拡張性の向上

- **モジュール分割とテスト容易性**:
  - パーサー、アニメーションエンジン、ピクセル合成などのドメインロジックが Rust のクレートとして完全に独立するため、単体テスト（`cargo test`）や機能改変が安全。
- **プラグイン / SHIORI 拡張アーキテクチャ**:
  - 外部シェルやカスタムSHIORIロジックをサンドボックス化された安全な WASM バイナリとして動的にロード・実行可能。
- **Rust エコシステムの活用**:
  - 豊富なクレート（`serde`, 正規表現パーサー等）をそのまま利用でき、TypeScript / JavaScript 製ライブラリのバージョン差異や型定義メンテの負担を軽減。
