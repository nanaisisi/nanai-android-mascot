# 2. SSP / MATERIA 風 起動時・処理中ステータスバナー（「処理中」ウィンドウ）

### 画面レイアウト・表示仕様

伺か／MATERIA・SSPにおいて、起動時やSHIORIロード中・重いイベント処理中に表示されるステータス表示ウィンドウ（処理中バナー）の構成仕様です：

```text
+-------------------------------------------------------------+
|  [ゴーストバージョン等]                  【 処 理 中 】     |  <- 上部 (約 3:2 の 3 相当)
|                                                             |
+-------------------------------------------------------------+
|  ゴースト名 (例: 「エミリ」)                                |  <- 下部 (約 3:2 の 2 相当)
+-------------------------------------------------------------+
```

- **上下 3:2 分割の構造**:
  - **上段（約 3）**:
    - **左上（小フォント）**: ゴーストのバージョン番号や著作情報・システム情報。
    - **右上（太字・大フォント）**: 「**処理中**」（あるいは動作状態ステータス）。
  - **下段（約 2）**:
    - **下部（中フォント）**: 対象ゴースト名（`descript.txt` の `name`）。
- **背景・装飾**:
  - ベースウェア共通の標準システムスタイル（濃紺／ダークグレー基調、または半透明ウィンドウによる矩形バナー）。独自スキンの合成は行わない。
- **表示位置（ウィンドウ配置座標）**:
  - 対象モニター画面において、**メニュー表示位置の左右反対側の下側**に配置する。
  - 例: メニューがタスクトレイ近傍の画面右下基準（`pos.x + width - 260`, `pos.y + height - 560`）の場合、バナーは**画面左下基準**（`pos.x + 20`, `pos.y + height - 140` など）に配置し、操作メニュー・通知領域との重複を回避する。
- **目的と消去タイミング**:
  - プロセス起動から SHIORI の初期化（`load` 完了）、`OnBoot` 応答の受け取り、初期サーフィスの描画準備が整うまで最前面に表示。
  - サーフィス表示完了と同時にフェードアウト／即時非表示。
