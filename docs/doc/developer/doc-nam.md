# Nanai Android Mascot (NAM) - 基本指針・仕様説明

## 1. ソフトウェア仕様の簡潔な説明

Nanai Android Mascot (NAM) は、伝統的なデスクトップマスコット規格「伺か（UKAGAKA）」を最新のマルチプラットフォーム環境（Windows / Android）で再現・進化させるためのオープンソース互換基盤です。Tauri v2 + Rust + Vanilla Web（HTML5 / Canvas）技術を中核とし、スマートフォン向けの現代的代替環境と、Web標準技術を活用した高アクセシビリティなプラットフォームを提供します。

## 2. 既存の基本指針

- **Windows First から Android 適応へ**: デスクトップ（Windows）環境で互換コアの実証を優先し、その後にAndroid向けの最適化を段階的に行う。
- **AI・LLM 駆動開発**: AIの支援を受けながら、方針決定・技術検討と実装をアジャイルに推進する。
- **規格互換の徹底**: SHIORI、さくらスクリプト、surfaces.txt、バルーン仕様など、UKADOC等で定義された伺か標準規格およびSSP拡張仕様との互換性を可能な限り保つ。

## 3. 開発・実装に関する新たな行動指針

本プロジェクトでは、コードの品質と互換性の正確性を担保するため、以下の指針を徹底します。

- **実装の精査**
  常に既存の実装プロセスやコードの妥当性をレビューし、技術的負債を減らすこと。
- **SSP等での不明仕様の文面化（無知の知）**
  公式ドキュメントに記載のないSSP等の挙動やエッジケースに遭遇した場合は、推測で実装せず、まず「不明仕様」として文面化する。自らの「無知の知」を前提とし、ドキュメントに記録してチーム（AIとユーザー）で共有する。
- **調査結果の実装への反映**
  文面化された不明瞭な仕様に対して検証・調査を行い、判明した正確な調査結果を随時仕様書へアップデートし、実装コードへと確実にフィードバックするサイクルを構築する。
