Nanai Android Mascot における「さくらスクリプト（Sakura Script）」規格への個別対応仕様です。

## 1. 概要と対応度

- **プロトコル規格**: さくらスクリプト（Sakura Script Specification）
- **対応度**: **85%**
- **主要実装ファイル**:
  - `crates/ui/src/script/`: さくらスクリプトのパーサー（Rust 統一実装。`parse_sakura_script` Tauri コマンドとして公開）
  - `ui/js/ghost/sakura-script.js`: スクリプトキューイングおよび実行制御
  - `ui/js/ghost/sakura-play.js`: トークン列の非同期文字送り再生
  - `ui/js/ghost/sakura-command-handler.js`: `\![...]` 拡張コマンドのディスパッチ

## 2. タグ別対応マトリクス

| タグ            | 機能                         |  対応状況   | 動作仕様・実装詳細                                                                           |
| :-------------- | :--------------------------- | :---------: | :------------------------------------------------------------------------------------------- |
| `\0`, `\h`      | メインキャラ（sakura）選択   |  ✅ 対応済  | スコープを `\0` に設定し、メインバルーン・サーフィスへ出力                                   |
| `\1`, `\u`      | サブキャラ（kero）選択       |  ✅ 対応済  | スコープを `\1` に設定し、サブキャラバルーン・サーフィスへ出力                               |
| `\p[n]`         | 追加キャラ（スコープ n）選択 | ⚠️ 部分対応 | 基本スコープ管理。多体配置時は単一透過レイヤー内で対応                                       |
| `\s[ID]`        | サーフィス切り替え           |  ✅ 対応済  | Canvas 2D レンダラと連動して即時表情・ポーズ変更                                             |
| `\w[N]`         | ウェイト（待ち時間）制御     |  ✅ 対応済  | 1〜9の指定値に応じた文字間ウェイト（例: `\w5` は 250ms）                                     |
| `\_w[N]`        | ミリ秒指定ウェイト           |  ✅ 対応済  | `\_w[500]` 等の指定ミリ秒間、文字送りを一時停止                                              |
| `\n`            | 改行                         |  ✅ 対応済  | バルーン内のテキスト改行                                                                     |
| `\n[half]`      | 半行改行                     |  ✅ 対応済  | 半行分の余白（マージン）を挿入                                                               |
| `\q[表示名,ID]` | 選択肢ボタン生成             |  ✅ 対応済  | クリック・タップ可能なインラインボタンをバルーン内に描画し、選択時に `OnChoiceSelect` を発火 |
| `\_a[ID]...\_a` | アンカーリンク               |  ✅ 対応済  | テキストリンクを生成し、タップ時に `OnAnchorSelect` を発火                                   |
| `\e`            | スクリプト終了               |  ✅ 対応済  | トーク終了、タイマーリセット、入力待機状態へ遷移（`\e` 以降のトークンは再生しない）           |
| `\c`            | バルーンクリア               |  ✅ 対応済  | バルーン内の表示文字を即時クリア                                                             |
| `\b[ID]`        | バルーン指定                 |  ✅ 対応済  | バルーン切り替え（`\b[0]` 基本、`\b[-1]` 非表示、数字形式 `\b0`〜`\b9` も対応）              |
| `\x`            | クリック待ち                 | ⚠️ 部分対応 | タップ/クリックされるまで文字送りを保留                                                      |
| `\_q`           | クイック描画トグル           | ⚠️ 部分対応 | タグ以降のテキストを一括即時表示                                                             |
| `\i[ID]` / `\i[ID,wait]` | アニメーション再生 |  ✅ 対応済  | サーフィスアニメーションの直接再生（`wait` で完了待ち）、`\i0`〜`\i9` 旧形式にも対応         |
| `\![raise,...]` | イベント強制発火             |  ✅ 対応済  | さくらスクリプト側からの SHIORI イベントディスパッチ                                         |
| `\![bind,cat,part,opt]` | 着せ替えパーツ制御   |  ✅ 対応済  | カテゴリ・パーツ名を指定した着せ替え有効化/無効化                                            |
| `\![...]` その他 | 拡張コマンド汎用透過        |  ✅ 対応済  | Rust パーサーが未知の `\![...]` を `Command` トークンとして透過し、JS 側ディスパッチへ接続   |
| `\t`            | タイムクリティカルセクション |  ✅ 対応済  | スクリプトブレーク（選択肢選択・ダブルクリック中断）か `\e` までマウス系イベント通知を抑止 |
| `\-`            | ゴースト終了                 |  ✅ 対応済  | スクリプト終了時にゴースト終了（終了イベント処理）を実行                                     |
| `\_s`           | 同期表示トグル               | ⚠️ 部分対応 | 複数キャラの同時文字送りトグルの解釈                                                         |
| `\_l[X,Y]`      | テキスト描画座標オフセット   | ⚠️ 部分対応 | バルーン内テキスト描画位置のオフセット設定                                                   |
| `\f[タグ,値]`   | フォント属性指定             | ⚠️ 部分対応 | `\f[bold]`, `\f[color,red]` 等のフォント属性指定トークンの解釈                               |

## 3. インタラクション仕様

- **全文スキップ**: バルーンまたはキャラクターのタップ/クリックにより、再生中のさくらスクリプトを即時全文表示。
- **選択肢操作**: `\q` で生成されたボタンはタッチ操作に最適化されたパディングで描画し、選択時に `OnChoiceSelect` を送信。
- **アンカー操作**: `\_a[ID]ラベル\_a` はクリッカブルなリンクとしてバルーン内に描画され、クリック時に `OnAnchorSelect` (Reference0: ID) を送信。
- **タイムクリティカル区間**: `\t` が指定されている間は、スクリプト再生中のマウスつつき・撫でイベント通知を抑止。
