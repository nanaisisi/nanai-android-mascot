# 階黙のSSP仕様：バルーンメニュー

本文書は、伺か互換ソフト「Nanai Android Mascot」におけるバルーンメニュー（システムネイティブメニュー等）における、明示的に文書化されていない（暗黙の）SSP仕様を策定したものです。

## 1. はじめに

バルーンメニューにおけるユーザー操作およびスクリプト挙動の多くは、SSP（Simple Script Player）の公式ドキュメントには明記されていない暗黙の仕様に依存しています。本文書は、それらの不明確な挙動を「無知の知」として文面化し、実装の精査および今後の互換性確保のための基準とします。

## 2. バルーンメニュー操作に関する暗黙仕様

| No. | 仕様項目                 | 説明                                                                                                                                                                                                                                     |
| --- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **何もしない**           | バルーンメニュー内の空白領域や、特にアクションが定義されていない領域へのクリックやタップは、何の処理も実行しない（デフォルトでは画面切り替えや閉じ込めなどを行わない）。                                                                 |
| 2   | **左クリックと同じ**     | バルーンメニュー項目への左クリック（またはタップ）は、通常の左クリックと同等の動作をする。スクリプト定義のアクション（項目遷移、コマンド実行等）が実行される。                                                                           |
| 3   | **スクリプトブレーク**   | バルーンメニュー表示中の特定の条件下で、スクリプト実行が中断または強制終了することがある。主に長時間表示または特定のタグ組み合わせ時に観察されるが、正確なトリガー条件についてはさらなる調査が必要。                                     |
| 4   | **バルーン左右切り替え** | バルーン表示位置の左右切り替え操作（ホットキーまたはタップジェスチャー）により、現在表示されているバルーンを左右のサイドに切り替える。この操作は、スクリプトの `\\s[ID]` 等の表情切り替えとは独立に動作する。                            |
| 5   | **バルーン位置調整**     | ユーザーがバルーンをドラッグまたはスワイプすることで、画面上の任意位置へ移動させることができる。移動後の位置はセッション保存され、次回起動時にも復元される。                                                                             |
| 6   | **ゴースト本体移動**     | バルーンメニューからゴースト本体（キャラクター本体）の移動操作を行う場合、バルーンと同様のドラッグ操作でゴースト本体の位置を調整できる。ゴーストとバルーンの位置関係は独立して管理されるが、ウィンドウ全体の移動時は連動することがある。 |

## 3. 今後の方針

- **実装の精査**: 上記仕様に基づき、実際のコード実装との照合を行い、相違がある場合は修正を優先する。
- **不明仕様の調査**: スクリプトブレーク（項目3）に関しては、再現環境と条件を特定し、公式SSP仕様との整合性を図る。
- **フィードバックループ**: ユーザーからの報告やテスト結果に基づき、仕様を随時更新・修正する体制を構築する。
