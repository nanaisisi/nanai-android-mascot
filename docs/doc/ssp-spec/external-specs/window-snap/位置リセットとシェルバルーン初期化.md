## 3. 位置リセットとシェル/バルーン初期化

シェル（キャラクター）およびバルーンの画面外退避や配置崩れを標準位置へ戻すための初期化仕様、ショートカットキー連携、およびタスクバー抜きワークスペース（`work_area`）に基づく基準位置算出ルールを定める。

### 3.1 シェル位置初期化 (`reset_character_positions` / `reset-shell-position`)

- **ショートカットキー**: `Ctrl+Shift+F12`
- **発火経路**:
  - キャラクターウィンドウ内のキーボード入力（`ui/ts/surface/character.ts` の `onKeyDown` → `reset_character_positions` 呼び出し後に `initialPos` を更新）
  - コンテキストメニュー展開中のキーボード入力（`ui/ts/ui/context-menu-keyboard.ts` → `reset-shell-position`）
  - オーナードローメニュー「機能」サブメニュー項目「シェル位置初期化 (H)」（`ui/ts/ui/submenu-renderer.ts`）
  - さくらスクリプト `\![execute,resetwindowpos]`（`ui/ts/ghost/command-handler/system/desktop.ts` → `reset-shell-position` 実行後、`OnResetWindowPos` に `"shell"` を通知）
- **位置算出と適用仕様**:
  - メニューアクション `reset-shell-position`（または `resetwindowpos`）経由では、`set_character_scale({ scale: 1.0 })` による倍率初期化と `reset_character_positions` の呼び出しを行う（単一ページ UI の DOM スタイル・ドッキングクラスもクリア）。
  - バックエンド `reset_character_positions`（`src-tauri/src/commands/window/character_window/visibility.rs`）は、タスクバー抜きのワークスペース（`monitor.work_area()`、プライマリモニター優先・未取得時は各ウィンドウの `current_monitor()`）の論理座標とウィンドウ実寸法から `compute_default_character_position` により各スコープの既定位置を算出して再配置する。
    - メインキャラ（`scope_id == 0`）: ワークスペース右下基準 (`work_x + work_w - eff_w - 80.0`, `work_y + work_h - eff_h`)
    - サブキャラ（`scope_id >= 1`）: メインの左側に並ぶ配置 (`work_x + work_w - eff_w - 320.0 - (scope_id * 220.0)`, `work_y + work_h - eff_h`)
    - 初期配置・リセット時は算出した基準位置をワークスペース範囲内 (`[work_x, max(work_x, work_x + work_w - eff_w)]` × `[work_y, max(work_y, work_y + work_h - eff_h)]`) に収める（通常移動時は無制限）。
  - 再配置完了後、各キャラクターウィンドウへ `"character-positions-reset"` イベント（`{ scopeId, x, y }`）を送出してスナップ機能における `Initial` 基準座標を更新し、続けて `sync_balloon_position_impl` により全スコープのバルーン位置を同期する。

### 3.2 バルーン位置初期化 (`reset_balloon_positions` / `reset-balloon-position`)

- **ショートカットキー**: `Ctrl+Shift+F10`
- **発火経路**:
  - バルーンウィンドウ内のキーボード入力（`ui/ts/ghost/balloon-window.ts` の `handleBalloonWindowKeydown`）
  - キャラクターウィンドウ内のキーボード入力（`ui/ts/surface/character.ts` の `onKeyDown`）
  - メインウィンドウのグローバルキーボード入力（`ui/ts/core/events/setup.ts`）
  - コンテキストメニュー展開中のキーボード入力（`ui/ts/ui/context-menu-keyboard.ts` → `reset-balloon-position`）
  - オーナードローメニュー「機能」サブメニュー項目「バルーン位置初期化 (N)」（`ui/ts/ui/submenu-renderer.ts`）
  - さくらスクリプト `\![execute,resetballoonpos]`（`ui/ts/ghost/command-handler/system/desktop.ts` → `reset-balloon-position` 実行後、`OnResetWindowPos` に `"balloon"` を通知）
- **位置算出と適用仕様**:
  - メニューアクション `reset-balloon-position`（または `resetballoonpos`）経由では、`reset_balloon_positions` に加えて `set_balloon_offset`（`scopeId: 0, 1`, `x: 0, y: 0`）の呼び出し・DOM インライン座標のクリアを行う。
  - バックエンド `reset_balloon_positions`（`src-tauri/src/commands/window/balloon_window/position.rs`）は `AppState::balloon_offsets` をクリアし、全スコープに対して `sync_balloon_position_impl` を実行する。
  - オフセット未保存状態の `sync_balloon_position_impl` は `compute_default_balloon_offset` に基づき、メインキャラ（`scope_id == 0`）はキャラクター右側（ワークスペース右端からはみ出す場合は左側反転）、サブキャラ（`scope_id >= 1`）はキャラクター左側、Y オフセットは `-20 * scale` を適用した上で、Y 軸のみワークスペース範囲内へ絶対クランプする。
