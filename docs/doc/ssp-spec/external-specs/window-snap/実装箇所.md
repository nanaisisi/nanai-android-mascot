## 実装箇所

本仕様（ワークスペース基準の配置、バルーンの Y 軸絶対クランプ／X 軸無制限、シェルの境界無制限＆スナップ、`#coord-popup`、位置リセットショートカット）に対応する現在の実装ファイル群は以下の通りである。

> **旧記述の整理**: 以前は [`ui/windows/desktop-features.html`](../../../../../ui/windows/desktop-features.html) および [`ui/windows/desktop-features.ts`](../../../../../ui/windows/desktop-features.ts) の `resetPosition()`（`win?.center()` を呼ぶのみの仮 UI テンプレート）を参照していたが、現在の実機能は以下のバックエンド・フロントエンド・ショートカット連携モジュールに実装されている。

### バックエンド (Rust / Tauri コマンド)

- **バルーン表示・リサイズ・Y軸絶対クランプ (`work_area` / HiDPI)**:
  [`src-tauri/src/commands/window/balloon_window/show/mod.rs`](../../../../../src-tauri/src/commands/window/balloon_window/show/mod.rs)
  - `LogicalWorkArea`, `monitor_logical_work_area`, `window_scale_factor`: `monitor.work_area()` と `scale_factor()` によるタスクバー除外論理ワークスペース算出
  - `clamp_logical_position_y_only`, `needs_vertical_clamp`: Y 軸のみの絶対クランプ（X 軸は無制限）
  - `compute_default_logical_balloon_pos`, `show_balloon_window`, `resize_balloon_window`: 初期表示・保存オフセット適用・可視再表示・リサイズ時の位置制御
- **バルーン追従同期・オフセット保存・初期化**:
  [`src-tauri/src/commands/window/balloon_window/position/mod.rs`](../../../../../src-tauri/src/commands/window/balloon_window/position/mod.rs)
  - `PhysicalWorkArea`, `clamp_physical_position_y_only`: 物理座標でのワークスペース Y 軸クランプ
  - `compute_default_balloon_offset`, `compute_saved_offset_and_clamped_y`: ワークスペース幅基準の初期左右判定と保存時 Y 補正
  - `sync_balloon_position_impl`, `sync_balloon_position`, `reset_balloon_positions`, `save_balloon_offset_from_position`, `set_balloon_offset`: 同期・初期化・ドラッグ後オフセット保存
- **キャラクター初期配置・無制限配置・位置リセット**:
  [`src-tauri/src/commands/window/character_window/visibility/mod.rs`](../../../../../src-tauri/src/commands/window/character_window/visibility/mod.rs)
  - `work_area_to_logical`, `monitor_logical_work_area`, `compute_default_character_position`: `monitor.work_area()` 基準の右下デフォルト座標算出
  - `show_character_window`, `show_subchar_window`: 明示座標・リサイズ時の境界無制限配置
  - `reset_character_positions`: ワークスペース基準のシェル再配置、`"character-positions-reset"` イベント送出、バルーン同期
- **キャラクター倍率変更・バルーン同期**:
  [`src-tauri/src/commands/window/character_window/scale_balloon.rs`](../../../../../src-tauri/src/commands/window/character_window/scale_balloon.rs)
  - `sync_character_balloon`, `set_character_scale`, `resolve_character_scale_factor`: キャラクター座標をクランプせず倍率変更とバルーン同期を実行
- **Tauri IPC コマンド登録**:
  [`src-tauri/src/invoke.rs`](../../../../../src-tauri/src/invoke.rs)
  - `show_subchar_window`, `reset_character_positions`, `show_balloon_window`, `resize_balloon_window`, `set_balloon_offset`, `reset_balloon_positions`, `sync_balloon_position`, `save_balloon_offset_from_position`, `sync_character_balloon` の登録

### フロントエンド (スナップ・ドラッグ・追随ポップアップ)

- **スナップ判定コア・ツールチップ文字列生成**:
  [`ui/ts/surface/interaction/drag/snap.ts`](../../../../../ui/ts/surface/interaction/drag/snap.ts)
  - `pickMonitorWorkArea`: モニター一覧からウィンドウ中心に対応する `workArea` と `scaleFactor` を解決
  - `calculateWindowSnap`: `Initial` / `Monitor` / `Character` の X/Y 独立スナップ判定および `Ctrl` 無効化
  - `formatSnapTooltipText`: 2 行プレーンテキスト（`<x>,<y>` + スナップ軸表示省略形、2 行目 `Press Ctrl to disable`）の生成
- **キャラクターウィンドウ操作・スナップ統合・ショートカット**:
  [`ui/ts/surface/character.ts`](../../../../../ui/ts/surface/character.ts)
  - `SNAP_THRESHOLD_LOGICAL_PX` (`12`), `loadSnapContext`, `computeSnapForPosition`, `updateDragPopupFromCurrentPosition`, `commitSnapOnDragEnd`, `startCoordInterval`, `showCoordPopup`
  - `onKeyDown` / `onKeyUp` / `onWindowBlur`: `Ctrl` 押下状態追跡、ならびに `Ctrl+Shift+F12` (`reset_character_positions`) / `Ctrl+Shift+F10` (`reset_balloon_positions`)
- **キャラクターウィンドウ HTML / CSS (`#coord-popup`)**:
  - [`ui/character.html`](../../../../../ui/character.html): `#coord-popup` 要素定義
  - [`ui/css/character.css`](../../../../../ui/css/character.css): `.coord-popup` の 2 行表示スタイル（`white-space: pre-line`, `width: max-content`）
- **バルーンウィンドウドラッグ・オフセットポップアップ**:
  [`ui/ts/ghost/balloon-window/gesture.ts`](../../../../../ui/ts/ghost/balloon-window/gesture.ts)
  - `BALLOON_RESET_HINT_TEXT` (`"Reset: Ctrl+Shift+F10"`), `formatBalloonOffsetText`, `renderBalloonCoordPopup`: キャラクター基準オフセットとヒントの 2 行安全描画
  - `setupWindowGestures`: マウス・タッチドラッグ中の 50ms ポーリング表示と解放時の `save_balloon_offset_from_position` 呼び出し
- **バルーンウィンドウ初期化・ショートカット**:
  [`ui/ts/ghost/balloon-window.ts`](../../../../../ui/ts/ghost/balloon-window.ts)
  - `handleBalloonWindowKeydown`, `initBalloonWindow`: `Ctrl+Shift+F10` による `reset_balloon_positions` 実行
- **バルーンウィンドウ HTML / CSS (`#coord-popup`)**:
  - [`ui/balloon.html`](../../../../../ui/balloon.html): `#coord-popup` 要素定義
  - [`ui/css/balloon-window.css`](../../../../../ui/css/balloon-window.css): `.coord-popup`, `.coord-popup-line`, `.coord-popup-hint` スタイル
- **シングルページ UI / モバイルフォールバック補助**:
  - [`ui/ts/surface/interaction/drag/drag-motion.ts`](../../../../../ui/ts/surface/interaction/drag/drag-motion.ts), [`ui/ts/surface/interaction/drag/docking.ts`](../../../../../ui/ts/surface/interaction/drag/docking.ts): モバイル・シングルページモード向けの座標計算および画面端ドッキング退避
