## 5. 会話・対話仕様（Mock SHIORI / トーク）

### 5.1 基本イベント

- **OnBoot (起動)**:
  - `\0\s[0]モック起動しました。\w8画面の隅っこにお邪魔します。\e`

- **OnClose (終了)**:
  - `\0\s[3]システム終了します。\w8また呼んでくださいね。\e`
- **OnMouseClick (タップ反応)**:
  - **Head タップ**: `\0\s[1]頭部アンテナ、感度良好です。\e`
  - **Face タップ**: `\0\s[2]画面タップを検出しました。\e`
  - **Body タップ**: `\0\s[0]四角いボディは頑丈ですよ。\e`
- **OnSecondChange (定時・ランダムトーク)**:
  - 時刻通知、画面端スナップのアナウンスなど
