## 1. 概要

SSP および本アプリケーション（Nanai Android Mascot）における、キャラクター（シェル）ウィンドウおよび独立バルーンウィンドウの画面領域基準、境界制御（ボーダーコリジョン）、デスクトップスナップ、ドラッグ追随ポップアップ（`#coord-popup`）、ならびに位置初期化（ポジションリセット）の動作仕様を定める。

### 1.1 全体共通：タスクバー抜きのワークスペース基準 (`work_area`)

画面領域の境界・スナップ・初期配置の基準は、モニター全体の矩形（`monitor.position()` / `monitor.size()`）ではなく、**OS のタスクバーや Dock 等を除外したワークスペース領域（`monitor.work_area()`）**とする。

- **バックエンド (Rust / Tauri)**: `tauri::Monitor::work_area()` が返す位置およびサイズをワークスペース基準として使用する。
- **フロントエンド (TypeScript)**: Tauri `@tauri-apps/api/window` の `Monitor.workArea`（`workArea.position` および `workArea.size`）を優先参照する。未取得時や非 Tauri 環境では `monitor.position` / `monitor.size` またはブラウザの `window.screen.availLeft` / `availTop` / `availWidth` / `availHeight`（タスクバー除外の有効表示領域）にフォールバックする。
- **マルチモニター選択**:
  - ウィンドウ中心座標を含むモニターを優先して選択し、いずれのモニター領域にも含まれない場合は中心点からの距離が最小となるモニターの `work_area` を採用する（取得できない場合のみ `primary_monitor` またはデフォルトフォールバック領域を使用）。
  - キャラクター位置一括リセット（`reset_character_positions`）時はプライマリモニターを優先し、未取得時に各ウィンドウの現在モニターへフォールバックする。

### 1.2 HiDPI 環境における座標系とスケールファクタの一貫性

高 DPI（スケーリング 125% / 150% / 200% 等）および混合 DPI マルチモニター環境において、論理座標と物理座標の混在による位置ズレやクランプ誤差を防ぐため、以下の規則で統一する。

- **無効スケールの正規化**: `scale_factor`（`scaleFactor`）が `0` 以下または非有限値（`NaN` / `Infinity`）の場合は安全側として `1.0` に正規化する。
- **Rust バックエンド（論理座標計算）**:
  - `monitor.work_area()` の物理位置・物理サイズは `safe_scale` で除算して論理座標（`LogicalWorkArea` / `work_area_to_logical`）へ変換する。
  - 混合 DPI 環境で `LogicalPosition` 指定による OS 側の再スケーリング誤差を避けるため、確定した配置座標は `target * scale` で物理座標へ変換した上で `tauri::Position::Physical` によりウィンドウへ適用する。
- **Rust バックエンド（物理座標計算）**:
  - バルーンの追従同期（`sync_balloon_position_impl`）およびドラッグ後のオフセット保存（`save_balloon_offset_from_position`）は、`outer_position()` / `outer_size()` / `PhysicalWorkArea` を用いて物理ピクセル空間で一貫して計算する。
  - デフォルトオフセット算出（`compute_default_balloon_offset`）内の論理基準値（重なり `10.0`・間隔 `20.0`）には `safe_scale` を乗じて物理オフセットへ換算する。
- **フロントエンド（シェルスナップ・ポップアップ）**:
  - ウィンドウの `outerPosition()` / `outerSize()` および `Monitor.workArea` は物理座標系で比較・スナップ計算する。
  - スナップ判定閾値は論理 `12px` 基準（`SNAP_THRESHOLD_LOGICAL_PX = 12`）とし、対象モニターの `scaleFactor` を乗じた物理閾値 `Math.max(1, Math.round(12 * scaleFactor))` を使用する（例: `scaleFactor = 1.5` のときは `18px`）。
  - 非 Tauri ブラウザプレビュー環境では `globalThis.devicePixelRatio` を用いて同様にスナップ計算および位置移動の整合を取る。

### 1.3 ウィンドウ種別ごとの仕様比較

| 項目                           | バルーンウィンドウ (`balloon_window_*`)                       | シェルウィンドウ (`subchar_window_*`)                                  |
| :----------------------------- | :------------------------------------------------------------ | :--------------------------------------------------------------------- |
| **縦方向 (`Y`) 境界**          | **絶対クランプ** (`work_area` の縦範囲内に厳格制限)           | **制限なし** (画面外・タスクバー上への配置/移動可)                     |
| **横方向 (`X`) 境界**          | **制限なし** (ワークスペース外・モニター外への配置/移動可)    | **制限なし** (画面外・タスクバー上への配置/移動可)                     |
| **初期配置・位置リセット基準** | キャラクター相対デフォルト位置 + Y軸のみ `work_area` クランプ | `work_area` 右下基準の既定位置へ配置                                   |
| **スナップ機能**               | なし                                                          | あり (`Initial` / `Monitor` / `Character`、閾値 `12px`、`Ctrl` で無効) |
| **追随ポップアップ 1行目**     | `Offset: <x>,<y>` (キャラ基準相対オフセット整数)              | `<x>,<y>` に続けてスナップ発生軸のみ表記                               |
| **追随ポップアップ 2行目**     | `Reset: Ctrl+Shift+F10`                                       | `Press Ctrl to disable`                                                |
| **位置初期化ショートカット**   | `Ctrl+Shift+F10` (`reset_balloon_positions`)                  | `Ctrl+Shift+F12` (`reset_character_positions`)                         |
