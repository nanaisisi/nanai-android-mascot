# シェル・サムネイル仕様（thumbnail.png）

## 概要

`shell/<shell_name>/thumbnail.png` は、伺か（SSP / MATERIA 等）において各シェルのプレビュー・外観一覧として利用されるサムネイル画像ファイルです。

## 規格上の根拠・位置づけ

1. **シェルの構成要素としての位置づけ**:
   - 伺か／SSP のシェルディレクトリ仕様において、シェル選択メニューや設定プレビュー、切り替え画面等のガイド画像として配置されます。
   - 必須（Mandatory）ではなく**オプショナル（省略可能）**なファイルです。存在しない場合は、ベースウェア側で代替（非表示または共通プレースホルダ）として扱われます。

2. **対応ファイル名・フォーマット**:
   - `thumbnail.png`: 標準の PNG 形式。
   - `thumbnail.jpg` / `thumbnail.jpeg`: JPEG 形式（SSP 等の拡張）。
   - `thumbnail.pnr`: 旧 MATERIA / 互換仕様（画像左上 `(0, 0)` のピクセル色を透過色として自動処理する PNG/ビットマップ形式）。

3. **画像サイズ・仕様制約**:
   - 規格上の厳格な解像度・アスペクト比制限はありません（一般的なシェルではバストアップや全身の縮小画像、100x100〜200x200 程度が主流）。

4. **ゴースト側サムネイルとの区別**:
   - **シェルのサムネイル**: `ghost/<ghost>/shell/<shell>/thumbnail.png`（シェルの切り替え・着せ替え・外観プレビュー用）。
   - **ゴーストのサムネイル**: `ghost/<ghost>/thumbnail.png`（ゴースト一覧・起動選択メニュー用）。

## 本アプリケーション（nanai-android-mascot）における活用方針

### 起動時処理ウィンドウ（スプラッシュ／初期ロード画面）への適用

- **目的**: ゴースト起動中および初期サーフィス構築の待機中に、白画面や空の描画枠ではなく対象シェルのサムネイルを表示し、体感速度向上と表示崩れ防止を図る。
- **検出優先度**:
  1. `shell/<current_shell>/thumbnail.png`
  2. `shell/<current_shell>/thumbnail.jpg`
  3. `shell/<current_shell>/thumbnail.pnr`
- **フォールバック**:
  - 上記が存在しない場合は、ゴースト側の `thumbnail.png` を検索し、それも無い場合は共通のローディングスピナーまたはプレースホルダアイコンを表示する。
