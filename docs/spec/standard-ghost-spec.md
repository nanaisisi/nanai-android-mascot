## 1. 概要

本ドキュメントは、**Nanai Android Mascot** に標準同梱される公式サンプルゴースト（アセットフォルダ: `assets/ghost/mock_nanai`）のキャラクター仕様およびシェル・対話仕様を定義したものです。
萌えキャラ的な過度な装飾を排し、スマートフォン画面上でも邪魔にならず見やすい「**四角い箱型でシンプルなデジタルマスコット**」として設計します。

---

## 2. プロジェクト内での位置づけ

### 2.1 技術検証用公式モック

- **透過・表示検証**: 四角い箱型ボディによる境界線の明確な透過描画・ドラッグ移動テスト
- **当たり判定（Collision）検証**: 頭部・前面ディスプレイ・胴体など、タッチ／クリック領域の明確な区分け
- **サーフィス切替検証**: `\s[0]` 通常、`\s[1]` 笑顔、`\s[2]` 驚き、`\s[3]` スリープ等のシンプルな表情差分テスト
- **SHIORI / フォールバック対話検証**: DLL ロード不可環境（WebView / Android 初期）での Mock SHIORI 応答テスト

### 2.2 デザインコンセプト

- **ミニマル & クリーン**: ガジェット風・ブロック風のシンプルで親しみやすい形状。
- **軽量・視認性**: モバイル画面（縦画面 9:16 等）を過度に占有せず、端に寄せても自然な佇まい。
- **着せ替え拡張性**: アンテナ（八木・宇田アンテナ等）や耳、ヘッドドレスなどをシンプルに着脱可能な構造。

---

## 3. キャラクター設定

### 3.1 メインキャラクター（sakura / 0番）: モック (Mock)

- **種族**: ポータブル箱型コンテナ／ロボットユニット
- **外見**:
  - 角丸の四角い箱型ボディ（落ち着いたライトグレー／オフホワイト調）
  - 前面ディスプレイ部にシンプルな表情（ドット・デジタル記号風）
    - 通常: `● ●`
    - 笑顔: `^ ^`
    - 驚き: `O O`
    - 待機・スリープ: `- -`
  - 頭部に小型アンテナ（またはオプションパーツ用コネクタ）
- **性格・役割**:
  - Nanai Android Mascot の案内役兼テストユニット
  - 控えめで実直、少し機械的なマイペースさを持つ
  - タップされた部位（頭、画面、ボディ）やシステム状態（時刻、バッテリー）を素直に報告する

### 3.2 サブキャラクター（kero / 1番）: プチ (Petit)

- **種族**: 補助用小型キューブユニット
- **外見**:
  - モックの傍らに浮遊またはちょこんと乗る小型の直方体／キューブ
  - 単眼またはシンプルなインジケーターランプ
- **性格・役割**:
  - モックの相棒。短い電子音や要約した合いの手を入れる

## 4. シェル（グラフィック・サーフィス）仕様

### 4.1 ディレクトリ構成

```text
assets/ghost/mock_nanai/
├── ghost/
│   └── master/
│       ├── descript.txt          # ゴースト定義（sakura: モック / kero: プチ）
│       └── satori.dll / dic_*.txt # 辞書ファイル
└── shell/
    └── master/
        ├── descript.txt          # シェル情報・着せ替え定義
        ├── surface0.png          # モック 通常表情 (● ●)
        ├── surface1.png          # モック 笑顔 (^ ^)
        ├── surface2.png          # モック 驚き (O O)
        ├── surface3.png          # モック スリープ (- -)
        ├── surface10.png         # プチ 通常
        ├── surface0.svg          # ベクターマスターデータ
        └── surfaces.txt          # 当たり判定・アニメーション定義
```

### 4.2 当たり判定（Collision 矩形）設計

箱型構造のため、直感的な矩形判定を配置：

1. `Head`: 天板・頭部（なでる、つつく）
2. `Face` (Display): 前面ディスプレイ画面（タップで表情変化など）
3. `Bust` / `Body`: 胴体・下部フレーム（ドラッグ移動やボディタッチ）

## 5. 会話・対話仕様（Mock SHIORI / トーク）

### 5.1 基本イベント

- **OnBoot (起動)**:
  - `\0\s[0]モック起動しました。\w8画面の隅っこにお邪魔します。\e`

- **OnClose (終了)**:
  - `\0\s[3]システム終了します。\w8また呼んでくださいね。\e`
- **OnMouseClick (タップ反応)**:
  - **Head タップ**: `\0\s[1]頭部アンテナ、感度良好です。\e`
  - **Face タップ**: `\0\s[2]画面タップを検出しました。\e`
  - **Body タップ**: `\0\s[0]四角いボディは頑丈ですよ。\e`
- **OnSecondChange (定時・ランダムトーク)**:
  - 時刻通知、画面端スナップのアナウンスなど

## 7. 設計背景・モチーフ

- 四角い箱型ボディに頭部アンテナを備えたシンプルで頑丈なマスコット構造。
- スマホ画面での透過オーバーレイ表示において、画面端へのスナップ吸着や視認性を損なわないミニマルデザインを重視。
