# 2. 右クリックメニュー（オーナードローメニュー）互換仕様

SSP (Sakura Script Player) の公式標準右クリックコンテキストメニュー仕様に対する、本プロジェクトでの対応状況およびモバイル・デスクトップ（Tauri）向け再設計。

## SSP 2.x 標準コンテキストメニュー構造 (完全一致仕様)

|   #    | SSP 標準メニュー項目      | アクションID / HTML要素 | 本プロジェクト（Nanai）実装仕様                                                                                 | モバイル（Android）適応方針                           |
| :----: | :------------------------ | :---------------------- | :-------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------- |
| **1**  | 前回と同じ話を繰り返す    | `talk-btn`              | [ui-and-menu-spec.md](../../doc/design/ui/ui-and-menu-spec.md) にて前回会話の再再生 (`OnChoiceSelect` 等連携)    | タップによる再発話トリガー                            |
| **2**  | 自動会話                  | `autotalk-btn`          | ランダムトークタイマー (`OnRandomTalk`) のトグル制御                                                            | 設定モーダルでの自動会話切り替え                      |
| **3**  | メールチェック            | `biff-btn`              | POP3 / IMAP メール着信確認イベント (`OnBIFFBegin`, `OnBIFFComplete`) トリガー                             | バックグラウンド定期メールチェック                    |
| **4**  | ヘッドライン              | `headlines-btn`         | RSS / ヘッドラインセンサ連携                                                                                    | Web 標準 Fetch による RSS リーダー                    |
| **5**  | 着せ替え                  | `dressup-btn`           | surfaces `bind` オプションのパーツ単位トグル (`OnDressupChanged`)                                               | チェックボックス付きアパレル選択パネル                |
| **6**  | シェル切替                | `shell-btn`             | インストール済み着せ替えシェルの切替 (`OnShellChanging`)                                                        | シェルプレビュー付き切替シート                        |
| **7**  | ゴースト切替              | `ghost-btn`             | インストール済みゴースト一覧選択 (`OnGhostChanging`)                                                            | カルソール／カード選択 UI                             |
| **8**  | バルーン切替              | `balloon-btn`           | スタイル（吹き出し）テーマの切替 (`OnBalloonChange`)                                                            | 吹き出しテーマ選択                                    |
| **9**  | ネットワーク更新          | `update-btn`            | `updates2.dau` / `updates.txt` によるオンライン差分更新プロセス (`OnUpdateProcessExec`)                         | Wi-Fi 接続時更新・バックグラウンド更新                |
| **10** | ファイルからインストール  | `export-btn`            | ゴースト・バルーン archive (`.nar`, `.zip`) のドラッグ＆ドロップまたはファイルダイアログ取込                    | インストールマネージャー連携                          |
| **11** | アンインストール        | `uninstall-btn`         | ゴーストディレクトリ削除ダイアログ (`OnVanishSelected`)                                                         | アプリ内部データ領域からの安全な削除                  |
| **12** | 情報                      | `inquire-btn`           | SSP / ゴーストクレジット・バージョン情報表示                                                                    | アプリバージョン & クレジットダイアログ               |
| **13** | リードミー                | `readme-btn`            | `readme.txt` の内蔵ビュワー表示                                                                                 | モーダルテキストリーダー                              |
| **14** | 設定                      | `config-btn`            | 本体詳細設定ダイアログ (タイミング、フォント、スケール調整)                                                     | タブ形式のモダン設定モーダル                          |
| **15** | 終了                      | `close-btn`             | 対象ゴーストのクローズ処理 (`OnClose`)                                                                          | 個別終了                                              |
| **16** | 全て終了                  | `close-all-btn`         | アプリケーション全体の完全終了                                                                                  | 常駐サービス停止 & プロセス終了                       |
