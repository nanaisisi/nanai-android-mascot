# 標準メニューのサイジング仕様とデザイン哲学

本ドキュメントは、Tauri アプリケーション（`nanai-android-mascot`）における標準メニュー（コンテキストメニューおよびサブメニュー）のサイジング、高さ調整、およびレイアウトに関する設計哲学と実装仕様を記録するものです。

---

## 1. デザイン哲学: 「スクロールレス」と「動的ウィンドウ拡張」

- **スクロールバーの原則的禁止**:
  - 本家 SSP（伺か）のオーナードローメニューと同様に、標準メニュー内での垂直スクロールバー（`overflow-y: auto` / `scroll`）の発生は原則として禁止します（`overflow-y: hidden`）。
- **完全自動フィットと動的拡張**:
  - メニュー主要部とサイドバーのサイズは常にきっちり揃えられ、項目数が変化したり高さが必要になった場合には、スクロールで隠すのではなく、**ウィンドウ自体を動的に伸縮・拡張させてすべての項目を1画面に収める**設計とします。

---

## 2. 実装上の仕組み

1. **コンテンツ駆動の高さ算出 (`height: auto`)**:
   - メニューコンテナ（`.menu-container`）は固定の高さを持たず、配置されるボタンや区切り線の総量に追従して高さを決定します。
2. **`ResizeObserver` によるリアルタイムウィンドウリサイズ**:
   - フロントエンド（TypeScript）側で `ResizeObserver` を用い、メニュー本体のレンダリングサイズ（`document.body.scrollHeight`）の変化を検知。
   - Tauri ウィンドウ API (`getCurrentWindow().setSize`) を通じて、ネイティブウィンドウのサイズをコンテンツの高さにミリ単位で自動同期させます。
3. **サイドバーとの高さ同期**:
   - フレックスボックス（`align-items: flex-start` およびサイドバーの `align-self: stretch`）により、サイドバー（`.menu-sidebar`）もメニュー主要部の高さに正確に連動し、ズレのない美しいオーナードロー表示を実現します。
