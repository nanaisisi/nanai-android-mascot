## 1. 概案の趣旨と背景

nanai-android-mascot は、デスクトップ（Tauri）およびモバイル環境で動作する伺か（UKAGAKA）互換のゴースト・シェル・バルーン表示システムです。
さくらスクリプトの高速パース、ASTトラバーサル、SERIKOアニメーションのフレーム演算、高精細なピクセルバッファ合成（`SurfaceFrameBuffer`）など、フロントエンド側で処理する計算量が非常に多くなっています。

## 2. 移行がもたらす価値

- **パフォーマンスの飛躍的向上**: 仮想DOMやJSのGC（ガベージコレクション）によるフレームドロップやカクつきを排除し、滑らかな60FPSアニメーションと高速なスクリプト解釈を実現。
- **アーキテクチャの統一**: バックエンド（Tauri）の Rust とコアエンジン（WASM）の Rust で言語仕様・型システムを完全に統一。
- **Web API との強力な親和性**: `wasm-bindgen` および `web-sys` を通じて、ブラウザ/WebView標準の Canvas 2D / WebGL / Web Audio API を Rust 側から直接・高速に操作可能。
