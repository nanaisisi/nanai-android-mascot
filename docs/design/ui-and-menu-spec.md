## 1. 設計思想と基本方針

1. **機能の詰め込みやすさ（High Density & Discoverability）**
   - 伺か（SSP等）の伝統的なコンテキストメニュー形式を採用。
   - 画面占有を抑えつつ、テキスト＋ショートカットキー表記によって膨大な機能を整然と一覧・実行可能にする。
2. **階層化サブメニューによる容易な機能追加（Extensible Submenus）**
   - 新規機能（プラグイン、倍率、ツール、連携設定など）を追加する際、既存のレイアウトを崩さずサブメニュー階層にスムーズにプラグインできる構造。
3. **OSネイティブな親しみやすさ**
   - システムフォント（MS UI Gothic / Meiryo / Segoe UI）と青系ハイライト、区切り線を用いた信頼感のあるルック＆フィール。
   - OSのダークモード設定にも即時追従。

## 3. 各メニュー機能のディスパッチ仕様

メニューアイテム選択時のアクションは、`postMessage({ type: "menu-action", action })` を経由してメインコントローラー（`main.js`）で処理されます。

| アクション ID | 表示名 | 動作仕様 |
| :--- | :--- | :--- |
| `talk` | もう一度話す | `OnMouseClick` をシミュレートし、ゴーストに自発トークを要求 |
| `scale-[N]` | シェル倍率 (50%〜200%) | マスコット表示コンテナ（`.ghost-display`）のサイズを即時更新し、通知バルーンを表示 |
| `ghost` / `ghost-switch` | ゴースト切り替え | ゴースト管理モーダルを開き、登録ゴーストを一覧選択 |
| `balloon` | バルーン設定 | 吹き出しテーマ・フォント設定モーダルを開く |
| `scan` | フォルダ再スキャン | `assets/ghost/` ディレクトリを走査し、新規ゴーストを検出 |
| `plugins` | プラグイン・拡張機能 | インストール済み JS/WASM 拡張機能を一覧表示・トグル設定 |
| `settings` | 設定 | 自動起動、透過率、最前面表示などの環境設定モーダルを開く |
| `debug` | デバッグログ | リアルタイム通信ログ、エラー追跡、ログエクスポート |
| `help` | 情報・ヘルプ | バージョン、ショートカット一覧、ライセンス表記 |
| `minimize` | アイコン化・隠す | マスコットを半透明化（またはトレイ退避） |
| `close` | 終了 | お別れトーク後にウィンドウを破棄・アプリ終了 |

## 4. 拡張性の維持・追加手順

今後新しい機能やプラグインをメニューに追加する際は、以下のステップのみで完了します：

1. **`menu-iframe.html` への項目追加**:
   - `<button class="menu-item" id="newfeature-btn"><span>機能名 (X)</span></button>` を追記。
   - サブメニューにしたい場合は `.menu-item-wrapper` 内に `.submenu-container` を配置するだけ。
2. **`main.js` のアクションルーターへの追加**:
   - 即時実行処理の場合は `action === "newfeature"` の分岐を追加。
   - モーダルを開く場合は `newfeature-modal-content` を `index.html` に定義するだけで自動バインド。
3. **JS プラグインからの動的注入（Phase 2対応）**:
   - プラグイン SDK（`context.menu.registerItem(...)`）から DOM 操作なしでメニュー項目を動的挿入可能。

## 5. ウィンドウ構成とキャラクター表示仕様 (Desktop / Android)

| 項目 | Android (モバイル) | Windows / Desktop (PC) |
| :--- | :--- | :--- |
| **メインウィンドウ (`index.html`)** | 全画面 / オーバーレイコンテナ。キャラ・バルーン・メニューを統合表示 | 常駐管理・設定モーダル・メニュー配信コンテナ |
| **キャラクターウィンドウ (`subcharacter.html`)** | メインウィンドウ内描画にフォールバック | 独立透過ウィンドウ。スコープ0（`\0`）およびスコープ1〜（`\1`）を個別生成 |
| **移動・配置** | タッチドラッグ / 画面端スナップ | 各キャラウィンドウを独立してデスクトップ上でドラッグ・配置可能 |
| **コンテキストメニュー** | 長押しまたは画面右上ハンバーガーボタン | 各キャラ上での右クリック（該当スコープの右クリックメニュー表示） |
