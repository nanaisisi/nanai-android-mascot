## 規格上の根拠・位置づけ

1. **シェルの構成要素としての位置づけ**:
   - 伺か／SSP のシェルディレクトリ仕様において、シェル選択メニューや設定プレビュー、切り替え画面等のガイド画像として配置されます。
   - 必須（Mandatory）ではなく**オプショナル（省略可能）**なファイルです。存在しない場合は、ベースウェア側で代替（非表示または共通プレースホルダ）として扱われます。

2. **対応ファイル名・フォーマット**:
   - `thumbnail.png`: 標準の PNG 形式。
   - `thumbnail.jpg` / `thumbnail.jpeg`: JPEG 形式（SSP 等の拡張）。
   - `thumbnail.pnr`: 旧 MATERIA / 互換仕様（画像左上 `(0, 0)` のピクセル色を透過色として自動処理する PNG/ビットマップ形式）。

3. **画像サイズ・仕様制約**:
   - 規格上の厳格な解像度・アスペクト比制限はありません（一般的なシェルではバストアップや全身の縮小画像、100x100〜200x200 程度が主流）。

4. **ゴースト側サムネイルとの区別**:
   - **シェルのサムネイル**: `ghost/<ghost>/shell/<shell>/thumbnail.png`（シェルの切り替え・着せ替え・外観プレビュー用）。
   - **ゴーストのサムネイル**: `ghost/<ghost>/thumbnail.png`（ゴースト一覧・起動選択メニュー用）。
