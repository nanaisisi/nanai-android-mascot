# ユーザーガイド - Nanai Android Mascot

> **AI 関与について**: このドキュメントは GitHub Copilot / Antigravity の支援により作成・更新されました。

このガイドでは、**Nanai Android Mascot** の基本的な使用方法、操作体系、設定のカスタマイズ方法について説明します。

---

## 1. 概要

Nanai Android Mascot は、デスクトップおよびモバイル環境で動作する「伺か（UKAGAKA）」互換のマスコットアプリケーションです。
画面上にキャラクター（ゴースト）が常駐し、ランダムトークやタップ・クリックに応じた会話、表情変化を行います。

---

## 2. 基本操作

### 2.1 キャラクター操作

- **ドラッグ / スワイプ**: キャラクターを掴んで画面内の好きな位置へ自由に移動できます。
- **左クリック / タップ**:
  - キャラクターの各部位（頭部、胸部など）を触ることで、ゴーストが反応して会話（さくらスクリプト）を開始します。
  - 会話バルーンの表示中にクリック/タップすると、文字送りの早送りスキップが行われます。
- **右クリック / 長押し / メニューボタン**:
  - キャラクター上を右クリック（または右上の ☰ メニューボタン）することで、**伺か標準クラシックメニュー** が開きます。
- **画面端ドッキング退避**:
  - キャラクターを画面の端にドラッグすると、作業の邪魔にならないようコンパクトに一時退避（スナップ）します。再度タップすると元の表示に戻ります。

### 2.2 伺か標準クラシックメニュー

右クリックで開くメニューは、伝統的な伺か（SSP）の操作体系に準拠した多階層メニューです。

```text
クラシックメニュー項目:
├── おすすめ (R)              # ゴースト推奨リンク
├── ポータルサイト (T)        # 関連ポータルサイト
├── ネットワーク更新 (U)      # ゴースト・アセットの更新確認
├── ─────────────────────────
├── ヘッドライン/ニュース (H) # ニュースヘッドライン取得
├── プラグイン (P)            # 拡張プラグイン一覧・設定
├── メールチェック (M)        # メール着信確認イベント
├── シェル倍率 (S)            # 50% / 75% / 100% / 125% / 150% / 200%
├── バルーン倍率 (B)          # 80% / 100% / 120% / 150%
├── 設定 (O)                  # アプリケーション共通設定
├── ─────────────────────────
├── ゴースト切り替え (G)      # インストール済みゴースト一覧から切替
├── シェル (S) / 着せ替え (C) # 現在のゴーストのシェル着せ替え
├── バルーン (B)              # バルーンデザインの着せ替え
├── ─────────────────────────
├── 情報 (A)                  # バージョン情報
├── アイコン化 (I)            # 画面から最小化
├── ─────────────────────────
├── 終了 (W)                  # アプリケーション終了 (Ctrl+W)
└── 全て終了 (X)              # 関連プロセスの全終了 (Ctrl+Q)
```

## 3. ゴースト & シェル管理

### 3.1 同梱ゴースト (`mock_nanai`)

初回起動時は、標準公式ゴースト「**mock_nanai**」が自動的に読み込まれます。
相方（kero / \1）キャラクターとの掛け合いや、選択肢メニュー（`\q`）の動作テストが可能です。

### 3.2 ゴーストの追加

1. 伺か用ゴーストのフォルダを用意します。
2. アプリケーションの `assets/ghost/` ディレクトリにゴーストフォルダを配置します。
3. メニューの「ゴースト切り替え (G)」から新しいゴーストを選択します。

### 3.3 シェル（衣装・外見）の着せ替え

複数のシェルが含まれるゴーストの場合、メニューの「着せ替え (C)」からシェルを瞬時に切り替えることができます。

---

## 4. バルーン（会話枠）のカスタマイズ

メニューの「バルーン (B)」から、好みのデザインスタイルを選択できます：

- **標準モダン (Modern)**: 半透明グラスモーフィズムデザイン
- **クラシック伺か (Classic)**: レトロな Windows ウィンドウ風デザイン
- **コミック (Comic)**: マンガ風の吹き出しスタイル
- **ダークモダン (Dark)**: 目に優しいダークテーマ

---

## 5. キーボードショートカット

| キー操作 | 機能 |
| :--- | :--- |
| `Ctrl + W` | アプリケーションの終了 |
| `Ctrl + Q` | すべてのプロセスの終了 |
| `Ctrl + I` | アイコン化（最小化） |
| `Escape` | 開いているメニューやモーダルを閉じる |
