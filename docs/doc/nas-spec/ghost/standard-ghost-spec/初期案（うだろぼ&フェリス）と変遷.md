## 2. 初期案仕様の記録（`9f914598~1:docs/standard-ghost-spec.md`）

### 2.1 キャラクター設定

- **メインキャラクター（sakura）: うだろぼ (Udarobo)**
  - **種族**: 宇陀アンテナ付き箱型歩行ロボット
  - **外見**: 四角い箱型ボディ、頭部に特徴的な宇田アンテナ、歩行用脚部
  - **性格**: 電気系のネタ（詳細検討中）
- **サブキャラクター（kero）: フェリス (Ferris)**
  - **種族**: Rust 言語マスコット（カニ）の擬人化
  - **外見**: オレンジ色のカニモチーフ、Rust ロゴを模したデザイン、機械的な甲殻とギアパーツ
  - **性格**: 相棒役の立ち位置、Rust ネタ等

### 2.2 設計背景・モチーフメモ

- ストライクウィッチーズの八木・宇田アンテナに由来するデザイン着想
- 指導教官の八木氏に対して宇田氏が主体だったエピソードの反映（キャラクター設定としても「やぎうだろぼ先生」の方がしっくりきたかもしれないという振り返りメモあり）
- Rust 言語マスコット Ferris のオマージュ（公式ガイドライン準拠）

### 2.3 想定ファイル構成・設定案

- **想定ディレクトリ**: `assets/ghost/udarobo_ferris/`
- **想定 `descript.txt`**:
  - `name,うだろぼ&フェリス`
  - `description,技術とユーモアの箱型ロボットコンビ`
  - `shiori,rustshiori.dll`（将来構想として Rust 完全実装 SHIORI および `toml` 設定を想定）
- **想定サーフェス**:
  - `surface0000.png` / `surface0001.png`（うだろぼ）
  - `surface0010.png` / `surface0011.png`（フェリス）
