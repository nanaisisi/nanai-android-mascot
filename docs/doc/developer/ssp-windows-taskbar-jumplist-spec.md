# SSP Windows タスクバー・ジャンプリスト仕様書

本ドキュメントは、SSP（Sakura Script Player）の Windows タスクバー右クリックメニューにおける「タスク (Tasks)」領域および所属アイテム（Explorer, Calendar）の正確な仕様書です。

---

## 1. SSP Windows タスクバー「タスク」構成 (2アイテム)

SSP の Windows タスクバー右クリックジャンプリストにおいて、「タスク (Tasks)」カテゴリ配下には以下の 2つの専用アイテムのみが登録・提供されます：

```
【Windows タスクバー 右クリックジャンプリスト】
 ┌────────────────────────────────────────┐
 │  タスク                                │
 │    Explorer (エクスプローラー)         │
 │    Calendar (カレンダー)               │
 └────────────────────────────────────────┘
```

### 1. Explorer (エクスプローラー)
- **機能**: 現在アクティブなゴースト、シェル、またはユーザーデータディレクトリを OS のファイルエクスプローラーで直接開く（`open_ghost_directory`）。

### 2. Calendar (カレンダー)
- **機能**: カレンダーおよびスケジュール連携ダイアログを起動。

---

## 2. 実装構造

1. **Rust バックエンド (`src-tauri/src/commands/`)**:
   - `open_ghost_directory`: OS 標準ファイルエクスプローラーの起動。
2. **フロントエンド連携 (`ui/ts/core/app-actions.ts`)**:
   - アクション `explorer`（エクスプローラー起動）および `calendar`（カレンダーダイアログ表示）のハンドリング。
