# さくらスクリプト環境変数（単語置換 %m...）とゴースト単語辞書連携の推測仕様書

- **文書名**: `ghost-word-dictionary-spec.md`
- **対象**: さくらスクリプト環境変数 (`%me`, `%mp`, `%mh`, `%mc`, `%mt`, `%mz`, `%ml`, `%ms`, `%dms`, `%m?` 等)
- **関連ファイル**: `assets/ghost/emily4/ghost/master/aya_word.dic`, `docs/ukadoc-spec/list/sakura-script/environment-variable/`

---

## 1. 概要 (Overview)

さくらスクリプト内の環境変数 (`%me`, `%mp`, `%mh`, `%mc`, `%mt`, `%mz`, `%ml`, `%ms`, `%dms`, `%m?` 等) は、バルーン描画時にテキスト展開される環境変数である。
本仕様書は、実在するゴースト辞書（`emily4` の `aya_word.dic` 等）の構造解析および UKADOC 規格に基づき、ベースウェア（本アプリ）とゴースト（SHIORI）間における単語置換の調達・優先度制御ロジックを推測・規定する。

---

## 2. 単語置換の二重解決構造 (Two-Tier Word Resolution Architecture)

さくらスクリプト内の「単語-」系環境変数は、以下の優先順位に従って動的に解決される。

```
[さくらスクリプト描画処理 (%me / %mp / %m? 等の検出)]
         │
         ├──► 【第1優先】 ゴースト (SHIORI) へのイベント問い合わせ (On_\me, On_\mp 等)
         │        │
         │        ├── (200 OK: 置換単語あり) ──► ゴースト自作の単語を採用
         │        │
         │        └── (204 No Content / 未対応) ──┐
         │                                         │
         └──► 【第2優先】 ベースウェア内蔵標準辞書 ◄┘
                  │
                  └──► ベースウェアのデフォルト単語からランダム抽選して適用
```

### 【第1優先】 ゴースト側 SHIORI 辞書応答 (Ghost-Side Word Dictionary Response)
ベースウェアがスクリプト内で `%<変数名>` (例: `%me`, `%mp`) を検出した場合、アクティブな SHIORI へ対応するイベントリクエストを発行する。
- **イベントID命名規則**: `On_\<変数名>` (例: `On_\me`, `On_\mp`, `On_\mh`, `On_\mc`, `On_\mt`, `On_\mz`, `On_\ml`, `On_\ms`, `On_\dms`)
- **応答形式**: SHIORI は `200 OK` とともに `Value: <選択単語>` を返却する。
- **実証根拠**: `assets/ghost/emily4/ghost/master/aya_word.dic` (LINE 350-395)
  ```aya
  //**** 単語取得イベント *****************************************************************
  On_\ms  { ms }
  On_\mz  { mz }
  On_\ml  { ml }
  On_\mc  { mc }
  On_\mh  { mh }
  On_\mt  { mt }
  On_\me  { me }
  On_\mp  { mp }
  On_\dms { dms }
  ```

### 【第2優先】 ベースウェア側標準ビルトイン辞書 (Baseware Built-in Fallback)
SHIORI が `204 No Content` を返却した場合、または該当イベントが未定義の場合は、ベースウェア本体に組み込まれたデフォルト単語テーブルからランダム抽選して置換を行う。

---

## 3. 単語カテゴリと環境変数の対応一覧

| 環境変数 | 規格上のカテゴリ | SHIORI イベントID | 代表単語サンプル |
| :--- | :--- | :--- | :--- |
| **`%ms`** | 単語-本体側名 | `On_\ms` | メインキャラクター名 (`%selfname`) / スクリプト定義名 |
| **`%me`** | 単語-食物 | `On_\me` | カレーライス, ケーキ, ポッキー, おでん, りんご... |
| **`%mp`** | 単語-地名 | `On_\mp` | モスクワ, 秋葉原, 公園, 海, 宇宙空間... |
| **`%mh`** | 単語-店名 | `On_\mh` | コンビニ, 八百屋, 喫茶店, 松屋, 東急ハンズ... |
| **`%mc`** | 単語-社名 | `On_\mc` | マイクロソフト, ソニー, 富士通, シャープ... |
| **`%mt`** | 単語-技/事物 | `On_\mt` | ビンタ, キン肉バスター, 蹴り, 真空竜巻旋風脚... |
| **`%mz`** | 単語-モノ/人名 | `On_\mz` | パソコン, タブレット, 湯呑み, チョロQ... |
| **`%ml`** | 単語-集合 | `On_\ml` | 仲間, 人類... |
| **`%dms`** | 単語-フレーズ | `On_\dms` | 意外と近くにいた宇宙人, 食べられない大根... |
| **`%m?`** | 単語-非限定 | `On_\m?` (または全カテゴリ統合) | 全カテゴリからのランダム選択 |

---

## 4. ベースウェアにおける推奨実装方針

1. **スクリプト描画前処理**:さくらスクリプト内の `%m...` タグを検索。
2. **SHIORI 問い合わせ**: `app.ghostController` 経由で SHIORI へ `On_\<タグ名>` リクエストを発行。
3. **応答の適用**:
   - `200 OK` かつ `Value` が空でない場合 ➔ そのテキストで置換。
   - `204 No Content` または未応答時 ➔ ベースウェア内蔵辞書（または `options.randomWords`）からランダム選択して置換。

---

## 5. 根拠に関する注意点・検証上の限界 (Note on Evidence & Limitations)

> [!WARNING]
> 本仕様書に記載されている `On_\<タグ名>` (例: `On_\me`, `On_\mp`) による環境変数問合せルールは、**サンプルゴースト（`emily4` の `aya_word.dic` 等）の実例構造から逆引きした推測仕様 (Inferred Specification)** です。
>
> 以下の点について、現時点で公式規格上の決定的な根拠が十分とは言えません：
> 1. **全 SHIORI サブシステムでの標準化の有無**:
>    `aya_word.dic` は AYA/YAYA 系の辞書構成例ですが、他の SHIORI サブシステム (里々, KAWARI, 華和梨2/3 等) において `On_\me` 形式のイベント ID が一律に標準規格として定義・実装されているかは不明です。
> 2. **ベースウェア (SSP 等) 側での送信実装の実態**:
>    SSP 本体のソースコードや公式仕様書において、ベースウェアがスクリプト描画時に一律で `On_\me` リクエストを SHIORI へ送信しているかについての公式記述は限定的であり、実機での挙動検証が必要です。
>
> したがって、本仕様は確定された公式規格ではなく、**「サンプルゴーストの実装パターンに基づく推測仕様」** として扱い、実装時にはベースウェア側フォールバックを常に有効にしておくことが必須です。
