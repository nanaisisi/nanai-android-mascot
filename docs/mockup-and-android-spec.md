# nanai-android-mascot UI/UX & モックアップ仕様書

本仕様書は、デスクトップおよび Android 端末上で動作する透過マスコット互換ソフトウェア「**nanai-android-mascot**」における UI/UX 設計、モバイル対応インタラクション、および開発・検証用モックアップの要件を定義します。

---

## 1. 基本コンセプトと目的

1. **Android 上での透過常駐マスコットの実現**
   - かつて存在したモバイル向け伺かプレイヤーの代替となる、モダンな常駐透過マスコットアプリを提供。
   - 他のアプリ起動中やホーム画面上でも邪魔にならず、親しみやすく快適に共存できる UI/UX を追求。
2. **PC と Android のクロスプラットフォーム検証**
   - Tauri v2 を基盤とし、PC 上で Android 相当の挙動や画面配置をシミュレート・検証できるモックアップ環境を構築。
3. **開発を止めないモックシステム**
   - SHIORI（DLL / 共有ライブラリ）のプラットフォーム依存に関わらず、フロントエンドや UI の開発を並行して推進できるモックゴースト・モック対話エンジンの提供。

---

## 2. モックアップ要件

### 2.1 UI/UX シミュレーションモック（PC 開発環境用）
PC 開発環境（ブラウザ / Tauri デスクトップ版）において、Android の画面アスペクト比（例: 9:16、360×640px 相当）およびタッチ操作を模倣する「**モックフレームモード**」を提供する。

* **フレーム切り替え機能**:
  * 通常ウィンドウモード（デスクトップ動作）
  * モバイルモックモード（スマホ画面枠＋透過プレビュー）
* **タッチシミュレーション**:
  * マウスドラッグをタッチスワイプ・ドラッグとして解釈
  * マウスクリックの長押し（ロングプレス）判定

### 2.2 公式モックゴースト（`mock_nanai`）
[assets/ghost/mock_nanai](file:///e:/project/rust/nanai-android-mascot/assets/ghost/mock_nanai) を、仕様検証・UI 開発用公式モックアップアセットとして位置付ける。

* **サーフィス構成**:
  * [surface0.png](file:///e:/project/rust/nanai-android-mascot/assets/ghost/mock_nanai/shell/master/surface0.png)（基本待機状態）
  * [surface10.png](file:///e:/project/rust/nanai-android-mascot/assets/ghost/mock_nanai/shell/master/surface10.png)（サブ・表情差分）
  * [surfaces.txt](file:///e:/project/rust/nanai-android-mascot/assets/ghost/mock_nanai/shell/master/surfaces.txt)（当たり判定・アニメーション定義）
* **モック対話（Mock SHIORI）**:
  * DLL ロードが不可能な環境（WebView 単体やモバイル開発初期）向けに、TypeScript/Rust 内部で以下のような主要イベントをシミュレート応答するフォールバックを実装:
    * `OnBoot`（起動挨拶）
    * `OnSecondChange`（定時・ランダムトーク）
    * `OnMouseClick` / `OnTouch`（タップ時の反応）

## 3. モバイル向け画面レイアウト仕様

### 3.1 画面配置

```
┌──────────────────────────────────────┐
│ 12:00                    📶 🔋 100%  │  ← システムステータスバー
├──────────────────────────────────────┤
│                                      │
│  [他アプリアイコンやホーム画面]        │
│                                      │
│                 ╭─────────────╮      │
│                 │ こんにちは！│      │  ← バルーン（吹き出し）
│                 │ ナナイだよ♪ │      │     (タップで進行/閉じる)
│                 ╰───  ────────╯      │
│                     ▽                │
│                   (\_/)              │
│                  ( •ᴗ•)  💬          │  ← sakura（マスコット本体）
│                  / >🍵               │     [💬 クイックバブル]
│                                      │
│                                      │
├──────────────────────────────────────┤
│              [  ●  ]                 │  ← システムナビゲーションバー
└──────────────────────────────────────┘
```

### 3.2 構成要素
1. **マスコット本体（Surface）**:
   * 背景完全透過の画像（PNG/SVG）レンダリング。
   * 画面内を自由にドラッグして移動可能。
   * 画面左右の端に近づけた場合、自動的に端へスナップ（吸着）して画面占有を抑える。
2. **クイックバブル（💬）**:
   * マスコットの近傍に小さく浮かぶ常時補助アイコン。
   * タップすることでメニューや話しかけ機能を素早く呼び出す。
3. **バルーン（Balloon / 吹き出し）**:
   * マスコットの頭上または空きスペースに自動配置。
   * 文字送りアニメーションと、さくらスクリプト（`\w`, `\n`, `\q` 等）に対応。
   * バルーン外タップまたは一定時間経過で自動非表示。

## 4. モバイル向けタッチインタラクション仕様

伺か（PC 向け）の標準的なマウス操作を、Android 向けに最適化してマッピングする。

| 操作種別 | モバイル入力 | 動作・発火イベント |
| :--- | :--- | :--- |
| **つつく / 話しかける** | 短いシングルタップ | SHIORI: `OnMouseClick` / リアクショントーク |
| **なでる** | 指で軽くこする / スワイプ | SHIORI: `OnMouseMove`（撫でカウント加算） |
| **メニューを開く** | 長押し（ロングプレス）<br>または 💬 バブルタップ | リングメニュー / ボトムシートの表示 |
| **位置移動** | 長押し後ドラッグ、または移動ハンドル操作 | ウィンドウ／オーバーレイ座標の更新 |
| **端への退避（最小化）** | 画面端へフリック | 半透明アイコン化し、画面端に格納 |

## 5. モバイル向けメニュー仕様（リングメニュー / ボトムシート）

片手・親指操作を考慮し、PC のコンテキストメニューを扇形（リング）メニューまたは下部ボトムシートとして展開する。

```
            ╭─── [ ⚙️ 設定 ] ───╮
            │                  │
    [ 🔄 切替 ]     ( ナナイ )     [ 💭 会話 ]
            │                  │
            ╰─── [ ✖ 隠す ] ───╯
```

### 主要メニュー機能
* **💭 会話**: 話しかける／もう一度話す（`OnChoiceSelect` / ランダムトーク即時実行）
* **🔄 切替**: インストール済みゴーストの切り替えモーダル呼び出し
* **⚙️ 設定**:
  * マスコットサイズ（倍率: 50% / 75% / 100% / 125% / 150%）
  * 不透明度（透過率スライダー）
  * 画面端スナップの ON/OFF
  * 会話頻度の設定（よく喋る / 普通 / 静かに）
* **✖ 隠す / 終了**:
  * 一時的に通知バーへ退避（最小化）、またはアプリ終了
